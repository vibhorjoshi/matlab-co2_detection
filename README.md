# Hyperspectral CO₂ Detection — Stagewise Pipeline with CT-ACE

![MATLAB](https://img.shields.io/badge/MATLAB-R2021a%2B-orange?style=for-the-badge&logo=mathworks)
![License](https://img.shields.io/badge/License-MIT-blue?style=for-the-badge)
![Data](https://img.shields.io/badge/Data-AVIRIS--NG-green?style=for-the-badge)

A MATLAB framework for detecting atmospheric CO₂ plumes from hyperspectral imagery.  
The pipeline runs four detection stages in sequence — **CIBR → JRGE → SFA → CT-ACE** — and the final stage (Cluster-Tuned Adaptive Coherence Estimator) is the proposed method.

## How to Run (from a clean clone)

```matlab
git clone https://github.com/vibhorjoshi/matlab-co2_detection.git
cd matlab-co2_detection

% Add paths
addpath(genpath(pwd));

% Run the complete pipeline (generates all four figures)
run('src/main_pipeline.m')

% Or call individual detectors
[score, mask] = co2_cibr(cube, wavelengths);
[score, mask] = co2_jrge(cube, wavelengths);
[score, mask] = co2_sfa(cube, wavelengths);
[score, mask] = computectmf();                  % uses proposed_results.mat
[score, mask] = computectmf(cube, wavelengths); % in-memory cube
[score, mask] = computectmf(imgFile, hdrFile);  % raw ENVI pair
```

`main_pipeline.m` automatically locates `proposed_results.mat` in the repository root and writes all figures into `updated_output_file/`.

## Dataset

### `proposed_results.mat` (fallback)

This file contains **only**:

```matlab
cube         % [rows × cols × bands]  hyperspectral cube
wavelengths  % [bands × 1]            band centres in nanometres
```

It is intentionally kept free of any pre-computed detection scores or masks so that every run recomputes results from the raw spectral data.

Because a full AVIRIS-NG flightline exceeds 40 GB it cannot be hosted on GitHub. The 10 MB `.mat` file therefore serves as a lightweight, self-contained fallback that lets any user execute and evaluate the complete pipeline out of the box.

### Execution priority

1. Raw ENVI `.img` / `.hdr` files (preferred when available)
2. `proposed_results.mat` (automatic fallback)
3. Synthetic demo cube (generated only when neither of the above exists)

### Data scale handling

Some reflectance products arrive with very small numeric magnitudes.  
`computectmf` automatically detects this situation (median value < 1e-3) and rescales the cube so that the median lies near a typical surface reflectance of 0.3 **before** the absorbance transform. An adaptive floor (1st percentile of positive values) is then used instead of a hard-coded constant, preventing mass clamping of the optical-depth cube.

### Atmospheric correction

The AVIRIS-NG L2 products used by this project have already been atmospherically corrected by JPL’s ATREM algorithm.  
A second atmospheric correction (FLAASH, QUAC, \ldots) would be physically incorrect and would destroy the subtle CO₂ absorption features.  
The pipeline therefore works directly on the supplied surface-reflectance values and only performs:

- SWIR band selection (1500–2100 nm)
- Water-vapour exclusion (1800–1950 nm)
- Optional spatial median filtering

## Algorithms

All four detectors live as independent functions in `core algorithms/`.  
They share a consistent post-processing convention:

- Rectification of negative scores  
- 3 × 3 median filter  
- Normalisation to [0, 1]  
- Hotspot mask = pixels above the **95th percentile** of the score map, followed by `bwareaopen(..., 10)`

### Stage 1 — CIBR (`co2_cibr.m`)

Continuum Interpolated Band Ratio around the strong CO₂ feature:

```
Left continuum  : 1980 nm
Absorption band : 2005 nm
Right continuum : 2030 nm

CIBR = ((L_1980 + L_2030)/2) − L_2005
```

### Stage 2 — JRGE (`co2_jrge.m`)

Joint Reflectance and Gas Estimation performed inside the 2000–2100 nm window.  
Three iterations of linear-continuum residual fitting accumulate a gas-column estimate.

### Stage 3 — SFA (`co2_sfa.m`)

Spectral Fitting Algorithm.  
A dual-Gaussian CO₂ template (1575 nm + 2005 nm, L2-normalised) is correlated against mean-centred pixel spectra so that continuum shape does not dominate the score.

### Stage 4 — CT-ACE (`computectmf.m`) — Proposed Method

Cluster-Tuned Adaptive Coherence Estimator:

1. **Absorbance transform** `A = −log(R)` (Beer–Lambert linearisation)  
2. **Water-vapour exclusion** bands 1800–1950 nm removed  
3. **K-means (K = 4)** with fixed seed `rng(1)`  
4. **Per-cluster signed ACE** using a regularised covariance and the backslash operator  
5. Rectification → median filter → 95th-percentile threshold → `bwareaopen`

The same dual-Gaussian CO₂ template used by SFA is employed as the target signature.

## Why CT-ACE Improves upon the Earlier Stages

- Absorbance domain makes gas concentration additive rather than multiplicative.  
- Per-cluster statistics prevent bright or dark surface materials from contaminating a single global covariance.  
- The ACE quadratic form normalises each pixel by its own background energy, reducing false positives.  
- Fixed random seed and a single implementation guarantee that every figure is reproducible.

## Requirements

| Toolbox | Key functions used |
|---------|--------------------|
| Image Processing Toolbox | `medfilt2`, `bwareaopen`, `regionprops`, `imagesc` |
| Statistics and Machine Learning Toolbox | `kmeans`, `cov`, `prctile` |
| Mapping Toolbox (optional) | geospatial visualisation helpers |
| Hyperspectral Imaging Library (optional) | `hypercube` when loading raw ENVI files |

**Minimum MATLAB version:** R2021a  
The core algorithms run with only the Image Processing and Statistics toolboxes.  
The Hyperspectral Imaging Library is used solely for convenient ENVI loading; a pure `multibandread` path is also provided.
